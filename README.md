# SafeRatio - نظام التأمين الذكي

## نظرة عامة
SafeRatio هو نظام تأمين ذكي متكامل يهدف إلى تبسيط عملية حساب وتقدير أقساط التأمين مع تحليل المخاطر بشكل متقدم. النظام مبني باستخدام Django في Backend وReact في Frontend.

- Django & Django REST Framework
- PostgreSQL
- JWT Authentication

### Frontend:

- Tailwind CSS للتصميم
